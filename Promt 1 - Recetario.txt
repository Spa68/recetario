# QUÉ ES RECETARIO

Recetario es una aplicación multiplataforma (iOS, Android, Web/PC) que permite capturar recetas de cocina encontradas en redes sociales (Instagram, Facebook, YouTube, WhatsApp, webs) y almacenarlas en un repositorio personal consultable.

El principio de diseño central es: capturar con fricción mínima, guardar el contenido tal cual, consultar sin esfuerzo.

# DECISIONES YA TOMADAS (NO LAS CUESTIONES)

1. NO se usa IA/LLM para extraer, estructurar ni interpretar recetas.
2. NO se hace OCR de imágenes. Las imágenes se guardan tal cual.
3. NO se integran APIs oficiales de redes sociales.
4. Se guarda el TEXTO CRUDO tal cual se captura, más las imágenes.
5. Un parser determinista (regex + Open Graph + readability) puede pre-rellenar campos de forma BEST-EFFORT, nunca es requisito.
6. La captura en iOS se hace mediante Shortcuts (Atajos), porque Safari iOS no soporta Web Share Target.
7. La captura en Android/Web se hace mediante PWA con Web Share Target API.
8. La búsqueda es full-text sobre el texto crudo, no filtros por ingrediente.

# RESTRICCIONES CRÍTICAS (NO NEGOCIABLES)

A. COSTE CERO ABSOLUTO: todo el stack debe funcionar dentro de capas gratuitas permanentes. Coste mensual objetivo: 0 €.
B. SIN MÉTODOS DE PAGO: no se proporciona tarjeta de crédito, PayPal ni ningún otro medio de pago a NINGÚN servicio, ni siquiera para activar planes gratuitos.

E. NO introduzcas OCR (Tesseract, visión, etc.).
F. NO uses colas de procesamiento ni workers pesados. Todo debe ser lineal y simple.

# STACK OBLIGATORIO (TODO GRATUITO, SIN MÉTODO DE PAGO)

- Frontend: PWA con React (o Vue). Desplegada en Vercel (capa gratuita).
- Backend: Supabase Edge Functions (capa gratuita, 500,000 llamadas/mes).
- Base de datos: Supabase Postgres (capa gratuita, 500 MB).
- Autenticación: Supabase Auth (capa gratuita, 50,000 MAU).
- Storage de imágenes: Supabase Storage (capa gratuita, 1 GB).
- Extracción web: readability + open-graph-scraper (open source).
- Transcripción YouTube: yt-dlp --write-auto-sub (open source).
- Puente iOS: Shortcuts con "Mostrar en hoja de compartir", tipo "Cualquiera".
- Puente Android/Web: PWA + Web Share Target API.
- Dominio: subdominio gratuito de Vercel (*.vercel.app).

NO propongas Cloudflare R2, AWS, GCP, Azure, ni ningún servicio que requiera tarjeta de crédito para activarse, aunque su capa sea gratuita.

Si crees que necesitas algo fuera de este stack, pregúntame antes. No lo implementes por tu cuenta.

# MODELO DE DATOS (v1)

Receta {
  id
  titulo              // inferido o editado a mano
  texto_crudo         // el texto original tal cual
  imagenes[]          // URLs a Supabase Storage
  fuente_plataforma   // instagram | facebook | youtube | whatsapp | web | manual
  fuente_url
  etiquetas[]         // manuales o extraídas de hashtags
  notas_personales
  fecha_captura
  estado              // borrador | revisada
  // Campos derivados opcionales (best-effort, siempre editables):
  ingredientes[]      // { nombre, cantidad_texto }
  pasos[]             // { orden, texto }
}
